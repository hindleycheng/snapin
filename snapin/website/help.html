Snapin 闪贴 · 帮助中心

截了就贴，贴了就用。跨平台截图与标注工具使用指南。

快速开始

1. 下载安装

从 官网 下载对应系统的安装包：

  • macOS：下载 .dmg，拖入 Applications 文件夹
  • Windows：下载 .exe，双击安装
首次打开 macOS 版本时，系统可能提示"无法验证开发者"。前往「系统设置 → 隐私与安全性」点击"仍要打开"即可。

2. 授予屏幕录制权限（仅 macOS）

首次截图时，macOS 会提示授予"屏幕录制"权限。点击允许后需要重启 Snapin。

3. 开始使用

安装后 Snapin 常驻在系统托盘/菜单栏。按下全局快捷键即可截图：

  • Mac：⌘⇧A
  • Win：CtrlShiftA

如何激活

  1. 打开 Snapin → 侧边栏点击「授权激活」
  2. 输入购买时的邮箱
  3. 输入授权码（格式：SNPN-XXXX-XXXX-XXXX）
  4. 点击"立即激活"
激活成功后，本机写入凭证文件，之后无需联网即可使用全部功能。
一个授权码最多可激活 2 台设备。如需迁移，在「设置 → 授权」中点击"解绑本机"后即可在新设备激活。

区域截图

按下 ⌘⇧A 后屏幕进入取景模式：

  1. 拖拽绘制矩形选区
  2. 选区边缘 8 个手柄可微调大小
  3. 方向键微调 1px，Shift+方向键 10px
  4. 选区确定后自动进入标注模式

不标注直接输出：按 Enter 复制到剪贴板，按 Esc 取消。

贴图钉屏

将截图作为始终置顶的浮窗贴在屏幕上，用于对照参考。

  • F3 将剪贴板中的图片贴出
  • 拖动标题栏移动位置
  • 滚轮缩放大小
  • 点击 ◐ 切换透明度（100% / 70% / 40%）
  • 点击 ✕ 关闭贴图
可以同时贴多张图，每张独立操作。研发对照设计稿、教学演示时非常实用。

拾色器

屏幕任意位置取色，输出 HEX / RGB。

  1. 按 ⌘⇧C（或菜单栏 → 拾色器）
  2. 移动鼠标，放大镜实时显示 8x 像素 + 颜色值
  3. 单击取色 → 自动复制 HEX 到剪贴板 → 退出
  4. Esc 取消

长截图

自动滚动并拼接为一张长图（最多 30 屏）。

  1. 将目标窗口置于前台（如浏览器网页、长文档）
  2. 在 Snapin 菜单/主页选择"长截图"
  3. 点击"开始" → Snapin 自动滚动+逐帧截取+智能拼接
  4. 完成后显示预览，自动保存到 ~/Pictures/Snapin/
长截图期间请勿操作鼠标/键盘，否则可能导致拼接不准。

历史记录

所有截图自动保存在本地历史库（专业版功能）。

  • 侧边栏 → 历史记录 → 查看所有截图缩略图
  • 显示文件名、尺寸、时间、是否有标注
  • 可删除单条记录
截图与历史记录全部存储在本机，Snapin 绝不上传任何数据到云端。

常见问题

Q: macOS 提示"无法验证开发者"？

前往「系统设置 → 隐私与安全性」，找到 Snapin 点击"仍要打开"。这是 macOS 对非 App Store 应用的正常提示。

Q: 截图时画面黑屏？

macOS 需要授予"屏幕录制"权限。前往「系统设置 → 隐私与安全性 → 屏幕录制」，确保 Snapin 已勾选，然后重启应用。

Q: 可以在几台设备上使用？

一个授权码可激活 2 台设备（Mac/Win 通用）。需要迁移时在旧设备「设置 → 解绑本机」即可释放名额。

Q: 忘记授权码怎么办？

购买时授权码已发送到你的邮箱，搜索"Snapin"即可找到。如果邮件丢失，联系 support@snapin.app 提供购买邮箱验证后补发。

Q: 截图保存在哪里？

默认保存到 ~/Pictures/Snapin/（macOS）或 我的图片\Snapin\（Windows），可在设置中更改。

Q: 数据会上传吗？

绝不会。所有截图、标注、历史记录均存储在本机，Snapin 不收集任何使用数据。唯一的网络请求是首次激活时校验授权码（之后离线可用）和检查更新。

Q: 如何更新？

Snapin 内置自动更新。检测到新版本时会弹窗提示，点击确认即可后台下载安装。也可从官网手动下载最新版覆盖安装。
