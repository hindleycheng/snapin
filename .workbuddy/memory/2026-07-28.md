## Tauri 打包成功（核心难点解决）
- **根因**：Rust 1.85+ 的 #[tauri::command] 宏有 E0255 bug（__cmd__ 重复定义），但 Tauri 最新依赖需要 Rust 1.88+
- **解决方案**：把所有 #[tauri::command] 函数放到子模块 commands.rs（而非 lib.rs 顶层），绕过宏冲突
- Rust 版本锁定：rust-toolchain.toml → 1.88.0
- 项目重建：snapin-old 备份后，创建新骨架（lib.rs 入口 + commands.rs 命令 + main.rs 调用）
- xcap 0.4 API 适配：is_primary()/width()/height() 返回 Result，需 unwrap_or/?
- image 0.25 需显式 use image::GenericImageView 才能 .dimensions()
- 打包产物：
  - Snapin.app（macOS 原生应用）
  - Snapin_0.1.0_aarch64.dmg（44MB，Apple Silicon）
- 官网下载按钮已指向 assets/Snapin_0.1.0_aarch64.dmg
- macOS 未签名 app 需 xattr -cr 清除隔离属性
- 主界面 index.html 重写为完整功能页（首页快捷工具+授权激活+历史记录+设置），调用 Tauri invoke
